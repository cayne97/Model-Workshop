## 🧠 什么是 RVC 与 SVC？

### RVC（Retrieval-based Voice Conversion）

RVC 是目前最主流的开源语音转换框架，基于 VITS 技术。其核心优势是 **低延迟实时变声** 与 **高还原度歌曲翻唱**，是游戏直播、开黑变声、短视频 AI 翻唱的首选技术。它能把一段人声/歌声无缝替换成目标音色，且仅需少量干声数据即可训练出高质量模型。

### SVC（So-VITS-SVC）

SVC 是专为歌声转换优化的深度学习框架，在歌曲咬字还原、气息处理、音准适配上有独特优势，更适合追求极致音质的专业级 AI 翻唱创作。

> **注意：** RVC 与 SVC 的模型 **不通用**，下载前请确认格式。两者均与 GPT-SoVITS 等 TTS（文本转语音）工具定位不同，后者无法用于歌曲翻唱。
