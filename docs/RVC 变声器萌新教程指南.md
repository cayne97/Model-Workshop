## 选择模型

选择正确路径的 `.pth` 文件和 `.index` 文件：
- **pth 文件**: 音色文件（主要文件）
- **index 文件**: 索引文件（实时推理中意义不大）

⚠️ **重要提示**: 路径内不能含有中文名！

---

## 音频设备选择

**重要!!!** 如果你是第一次使用 RVC，从未安装过其他虚拟声卡之类的软件，请先安装虚拟声卡。

> RVC 并不能直接输出声音到麦克风，需要机架或者虚拟声卡将转换的声音发送到一个虚拟麦克风使用。

### 设备选择步骤

1. **输入设备**: 选择你的硬件麦克风
2. **输出设备**: 选择虚拟声卡输出线路 `VoiceMeeter Input (VB-Audio VoiceMeeter VAIO)`
3. **驱动类型**: 输入输出全部请选择末尾为 **MME** 的驱动

## 参数设置

以下是通用参数设置（通常这么设置肯定能用）：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 响应阈值 | -60 | 控制触发变声的音量阈值 |
| 音调设置 | 0 | 男转女 +12，女转男 -12，同性 0 |
| index rate | 0.5 | 索引混合比例 |
| 音高算法 | harvest | 推荐使用 |
| 采样长度 | 65ms | 决定变声延迟 |
| harvest 进程数 | 4 | 并行处理进程数 |
| 淡入淡出长度 | 0.05s | 平滑过渡 |
| 额外推理时长 | 0.1s | 预留缓冲时间 |

---

## 参数详解

### 1. 响应阈值
控制触发变声的音量阈值，低于此值不会进行变声处理。

### 2. 音调设置
- **男转女**: +12
- **女转男**: -12
- **同性别**: 0

### 3. index rate
索引混合比例，影响音色相似度。

### 4. 音高算法
推荐使用 `harvest` 算法，音质更好。

### 5. 采样长度（决定变声延迟）
- 越短延迟越低，但可能影响音质
- N 卡可低至 100ms 内

### 6. harvest 进程数
并行处理进程数，数值越高占用 CPU 越多。

### 7. 淡入淡出长度
平滑过渡长度，避免声音突变。

### 8. 额外推理时长
预留缓冲时间，确保推理稳定。

## 💡 新手避坑指南

1. **路径问题**: 90% 的问题源于文件/文件夹路径包含中文、空格或特殊符号，请务必使用全英文路径
2. **电音/底噪**: 通常是干声不纯净或变调参数错误
3. **模型加载失败**: 检查模型文件是否放入正确的权重文件夹
4. **实时变声延迟高**: 
   - N 卡可低至 100ms 内
   - 关闭后台占用显存的程序
   - 选择轻量化模型
